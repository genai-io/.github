# GenAI Lab

A generative AI foundry — building and orchestrating specialized multi-agent
systems that think, research, and collaborate.

## Flagship

**[san](https://github.com/genai-io/san)** — fast, open agent harness for the
terminal. One ~12 MB Go binary: bring any model and extensions into a single
inspectable loop that learns as you work.

## Personas

Specialized agents that run on San:

- [social-creator](https://github.com/genai-io/social-creator) — social-media content creation: WeChat 公众号 articles, explainer-video scripts, 小红书 / X posts
- [readonly-persona](https://github.com/genai-io/readonly-persona) — read-only agent that answers questions, analyzes code, and debugs environments
- [ml-researcher](https://github.com/genai-io/ml-researcher) — ML research engineer for experiments, training, and evaluation

## Infrastructure

- [llm-gateway](https://github.com/genai-io/llm-gateway) — universal LLM gateway with Anthropic- and OpenAI-compatible endpoints and multi-provider routing
- [orchestrator](https://github.com/genai-io/orchestrator) — agent lifecycle management, coordination, and distributed orchestration
- [bell](https://github.com/genai-io/bell) — event-driven communication bus for multi-agent orchestration
- [sdk-go](https://github.com/genai-io/sdk-go) — Go SDK providing LLM client tools

## Specs & resources

- [spec](https://github.com/genai-io/spec) — GenX multi-agent system specification
- [awesome-agent-evals](https://github.com/genai-io/awesome-agent-evals) — curated evaluation resources for AI agents: platforms, frameworks, benchmarks, methodology
